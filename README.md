# Primitive DB

Primitive DB — учебная консольная база данных на Python. Программа позволяет
создавать и удалять таблицы, добавлять, читать, обновлять и удалять записи.
Схемы таблиц хранятся в `db_meta.json`, а данные —
в JSON-файлах каталога `data/` в рабочей директории программы.

## Установка и запуск

Требуются Python 3.10 или новее и [`uv`](https://docs.astral.sh/uv/getting-started/installation/).
В корневой директории проекта выполните:

```bash
uv sync --locked
uv run database
```

Если установлен `make`, можно использовать:

```bash
make install
make run
```

Также доступна команда `uv run project`, вызывающая ту же точку входа.
В интерактивной консоли введите `help`, чтобы увидеть список команд, и `exit`,
чтобы завершить работу.

Проверка стиля и сборка пакета:

```bash
make lint
make build
```

## Управление таблицами

Имена таблиц могут содержать только латинские буквы, цифры и подчёркивание.
Для работы с таблицами доступны следующие команды:

- `create_table <имя_таблицы> <столбец:тип> ...` — создать таблицу. К указанным
  столбцам автоматически добавляется столбец `ID:int`. Поддерживаются типы
  `int`, `str` и `bool`.
- `drop_table <имя_таблицы>` — удалить таблицу.
- `list_tables` — вывести список таблиц.
- `help` — вывести справку по командам.
- `exit` — завершить работу программы.

Пример использования:

```text
Введите команду: create_table users name:str age:int active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, active:bool
Введите команду: drop_table users
Таблица "users" успешно удалена.
Введите команду: exit
```

## CRUD-операции

Все поля таблицы обязательны. Значение `ID` в команде `insert` указывать не
нужно. Строковые значения записываются в кавычках.
Одна команда `insert` добавляет одну запись в одну таблицу.

При обновлении проверяются типы значений и существование столбцов. 
Удаление таблицы удаляет и её файл данных;
повторное создание таблицы с тем же именем начинает работу с пустыми данными.

- `insert into <таблица> values (<значение1>, ...)` — добавить запись;
- `select from <таблица>` — вывести все записи;
- `select from <таблица> where <столбец> = <значение>` — найти записи;
- `update <таблица> set <столбец> = <значение> where <столбец> = <значение>` —
  обновить найденные записи;
- `delete from <таблица> where <столбец> = <значение>` — удалить найденные
  записи;
- `info <таблица>` — вывести схему и количество записей.

Пример:

```text
>>> Введите команду: insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".
>>> Введите команду: select from users where age = 28
+----+--------+-----+--------+
| ID |  name  | age | active |
+----+--------+-----+--------+
| 1  | Sergei |  28 |  True  |
+----+--------+-----+--------+
>>> Введите команду: update users set age = 29 where name = "Sergei"
Запись с ID=1 в таблице "users" успешно обновлена.
>>> Введите команду: delete from users where ID = 1
Запись с ID=1 успешно удалена из таблицы "users".
>>> Введите команду: info users
Таблица: users
Столбцы: ID:int, name:str, age:int, active:bool
Количество записей: 0
```
